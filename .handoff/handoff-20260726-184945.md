Ticket 06 要点：

- `Lion.py` 更新为标准 Lion v2 语义：
  - `update_direction = sign(beta1 * momentum + (1-beta1) * grad)`
  - `new_momentum = beta2 * momentum + (1-beta2) * grad`
  - `new_weight = weight - lr * update_direction`
- 新增 `lion_state_schema_version` saveable 标记。
- 旧 Lion optimizer 文件缺少 v2 标记时，不静默恢复旧 `c` slot；加载时发出 `UserWarning`，并重置 `iterations` 与 `c`。
- 旧模型主权重由各模型 Saveable 独立加载，不受 optimizer slot reset 影响。
- NumPy roundtrip harness 与测试改为 v2 公式，并覆盖 legacy payload reset / strict reject。
